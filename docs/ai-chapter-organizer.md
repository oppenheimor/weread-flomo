# 章节 AI 整理

## 当前行为

- 导航栏账号菜单 → 模型设置。服务商目录参考 frametell，支持 OpenAI 兼容、Anthropic Messages、Google Gemini 三种协议；预设地址可编辑，也可添加自定义服务商。
- API Key 按账号加密保存，普通响应只有 hasKey，不返回明文。留空保存保留原 Key；移除服务商会同时移除它的默认模型选择。
- 保存配置后可以获取模型列表，也可手动输入 ID。点星标设为全局默认模型；连接测试会发起一次小额度真实模型请求。
- 章节标题、进度与数量放左侧，视图及生成操作放右侧。未整理时显示「AI 整理本章」，没有模型配置则引导设置，设置后不自动请求。已有结果时显示「原始笔记 / AI 整理」分段切换，只切换视图、不触发生成也不删除结果。「重新整理」以刷新图标紧邻选中的「AI 整理」，仍保留覆盖编辑的确认；视图切换使用中性纸白选中态与轻边框，无绿底和下划线；刷新按钮与 AI 整理共享轮廓，以细分隔线区分。
- 来源仅取当前预览、同章节、ready 的标准化笔记，应用用户修改过的想法。每个来源在新结果中恰好出现一次。代码校验覆盖、重复、未知来源和正文长度，不能只靠 Prompt。
- 每组多个来源生成短标题与连贯正文；正文可用 `**重点**` 标注少量重点，页面安全渲染加粗，编辑及 flomo 正文保留原始 Markdown。单来源组忽略模型改写，保留原始内容。来源快照与 AI 正文分开存储，后续来源变化不自动覆盖快照。
- 当前支持显式思考控制的 DeepSeek OpenAI 协议模型（deepseek-v4-pro、deepseek-flash）默认快速整理，发送 `thinking.type=disabled`；首次整理按钮旁或 AI 整理视图操作旁可为下一次整理选择深度思考，显式发送 `enabled`。不切换用户模型、不自动重试；其他模型不注入未经确认的厂商参数，也不显示不支持的模式选择。接口依据：https://api-docs.deepseek.com/guides/thinking_mode 。
- 等待采用现场写作：章节工具栏不再展示装饰性小黑猫；首段输出前显示一行真实状态；真实返回的标题、正文逐步写入笔记卡片，提示移到下方。收到服务商推理事件后显示「模型正在思考，尚未输出正文」；不回传推理原文。不展示步骤条、耗时或字符数，不用模拟打字延迟。接口忽略流式请求时明确提示等待完整结果。
- 生成卡片只读，没有编辑、勾选或来源操作，整章严格校验完成后才显示这些控件。独立摘录直接使用来源快照原文与想法，忽略模型改写。
- 重新整理时隐藏旧结果，失败恢复旧结果；临时卡片不进入 ai_note，也不能发送。底部自动跟随，向上滚动时暂停，提供「回到生成位置」。
- 开始整理遇到明确的预览过期错误时，前端刷新书籍索引和笔记预览后再提交一次。网络超时、模型失败等其他错误不自动重试。
- 点击完成保存标题、正文，有版本检查防止多页面覆盖。离开未保存编辑时确认。
- 重新整理成功后原子替换 ready 结果，保留 sent/uncertain 历史；含编辑过的 ready 结果需确认。无可用来源拒绝生成且不清空旧结果。

## 任务

数据库保存章节任务状态和生成结果，进程内两个后台线程执行、最多八个待处理任务，每账号最多两个并行章节。同章不重复提交，生成中锁住旧结果编辑/同步，但允许浏览原始内容和切换章节。

浏览器只轮询当前章节的任务状态，不监听原始笔记变化。关闭页面不终止任务。服务重启后把遗留 running 任务置为 failed，不自动重新消费额度；旧结果不受影响。

单次上限 200 条来源 / 60,000 字符输入，输出预算 16,000 tokens，连接 15 秒、响应读超时 120 秒、普通 JSON 响应体与 SSE 公开正文各限 2 MB；SSE 线上传输另限 32 MB、单事件限 200 万字符，以免消息包装与推理流量挤掉正文预算。整理使用 SSE 流式接收，三种协议只提取公开正文；展示用草稿最多约每 60ms 写入一次，等待阶段客户端每 350ms 获取，接收正文时缩短至 80ms（请求串行，不重叠）。自动跟随采用可中断的平滑滚动，尊重减少动态效果设置；没有人为打字延迟。JSON 前缀解析器只提取真实返回的字段，处理转义和未完成字符串；它不替代最终校验。不支持流式但返回完整 JSON 的兼容接口使用同一次响应，不另发请求。超限和截断明确失败，不静默删减。旧模型若不支持输出预算可能返回错误，需要更换模型；当前不做隐式降级或自动重试。

## 同步语义

复用原来的 delivery / delivery_source 账本：

- 整理结果拥有 `ai:<UUID>` 的独立投递 ID。
- reserveOrganized 在事务中先校验自身与来源是否需核对，然后预留结果及尚未有账本的来源。已经 sent 的原始来源账本不覆盖、不降级。
- 成功把结果以及本次关联来源标为 sent。原始先发送，不影响多来源整理结果后发。
- 独立摘录复用来源状态，防止原始/整理两个视图重复发同一条独立摘录。
- 超时等未知结果标为 uncertain，关联未同步来源同样不可发送；确认未送达仅释放这次预留，保留早已 sent 的来源。
- 结果发送失败立即停止批次，不自动重发。只有明确成功或人工核对后才更新为 sent。

## 网络安全

AI HTTP 客户端独立于微信读书/flomo 客户端：不跟随重定向，不自动重试，不打印密钥或供应商响应错误正文。连接使用受控 DNS resolver，在实际建立连接时拒绝私网、回环、链路本地和非公网地址；地址不得包含用户名密码、查询参数或 IP 字面值。

默认只允许公网 HTTPS。自托管 Ollama 如确有需要，管理员可在后端环境中设置 `AI_TRUSTED_HOSTS=localhost`，显式允许对应域名的 HTTP/私网访问。该允许列表是服务端信任边界，所有已登录用户均可使用其中域名，不能允许云元数据域名。localhost 指服务器，不是浏览器所在电脑。部署层也应使用出站网络策略限制不必要访问。

## Magpie 网关

模型设置的「本地」分组内提供 Magpie 预设，默认地址 `http://localhost:3425/v1`（也可使用 `http://127.0.0.1:3425/v1`）。**Magpie 的模型列表、测试和生成全部由用户浏览器直接调用，不经过云端服务器。** 其他服务商保持后端调用。

1. 用户启动本机 Magpie 并配置上游。在 Settings → Network and sharing → Web pages 中添加本网站的准确 origin（协议、域名、端口，不含路径）。网页调用须填写 Gateway key；本机 Agent 的免认证规则不适用于网页。浏览器询问本地网络权限时允许；不支持此权限/跨域连接的浏览器将显示连接提示，不会降级为服务器代理。
2. 在模型设置中填写网关密钥，保存、获取模型、测试并设为默认。已填写的 key 可用「清除密钥」移除；清除后需重新填写才能连接。key 只留在当前标签页内存，不写 localStorage、sessionStorage 或服务器；刷新、退出登录及登录失效会清除。服务端拒绝上传 Magpie key，V9 迁移清除旧版已保存的该凭证。
3. 模型 ID 保留 `provider/model`、`auto/model` 或 `group/分组名`。只允许 localhost / 127.0.0.1 的 `/v1` 地址；请求禁带 Cookie、不跟随重定向。CSP 仅额外开放这两个回环主机，不放开任意公网地址。
4. **无需配置 AI_TRUSTED_HOSTS、开启局域网共享或暴露端口。** localhost 在此专指浏览器所在电脑。Magpie 的 Web pages 授权和浏览器本地网络许可仍须由用户设置。

生成流程：`/start` 为 Magpie 返回浏览器任务及提示词，服务器保留来源快照和 5 分钟租期；浏览器读取 SSE，将公开正文草稿节流提交至 `/browser/progress`，完整结束后提交 `/browser/complete`。服务端按用户、章节、任务 ID 核验，复用原有来源覆盖校验与事务替换逻辑。重复完成不会重复创建笔记，过期或旧任务不得覆盖新结果，失败保留旧稿。关闭页面会中断本地调用，未通知服务端的任务在租期结束后读取/重试时回收。整理期间应保持页面打开。

参考：[官方入门](https://usemagpie.ai/docs/start)。实际浏览器兼容性受 Magpie 版本、站点授权及浏览器本地网络权限影响。

## 数据与接口

V6 新增 ai_provider、ai_default、ai_chapter、ai_note，均按 user_id 隔离。V7 为章节任务增加进度字段（保留兼容，不再用于等待面板）。V8 新增 drafts 存储只读临时卡片，开始新任务、完成或失败时清空；非运行状态不向客户端返回草稿。原始同步表无需迁移旧记录。

`/api/ai/settings`、`providers`、`providers/delete`、`default`、`models`、`test` 管理模型。
`/api/ai/chapters` 保留即使来源已删除的历史章节入口。
`/api/ai/chapter`、`start`、`edit`、`send`、`resolve`、`refresh-preview` 管理整理与投递。
所有写操作继承登录、Origin 和 CSRF 校验。

## 验证

- `npm run build`
- `node --test scripts/markdown.test.ts scripts/ai-request.test.ts`：加粗片段、HTML 惰性文本、过期预览恢复和不重试不确定请求。
- AiDraftsTest / PostgresTest：不完整 JSON 标题和正文、转义字符、来源 ID 校验、独立摘录快照、不完整结果拒绝、草稿账号隔离、禁止编辑发送和失败恢复。
- AiStreamTest：验证超过 2 MB 的 SSE 包装/推理流量不会挤掉短正文，同时公开正文仍受独立上限保护；仅报告实际推理状态，不公开推理文本。
- 传输诊断仅记录请求随机标识、耗时、流式与否、字节数及异常类型，不记录密钥、笔记、推理原文或供应商错误正文。
- AiStreamTest / AiTransportTest：分块 UTF-8、三种 SSE 格式、过滤内部推理字段、截断拒绝、公开说明提取和真实 HTTP 流式接入。
- `bash scripts/test-postgres.sh`：在临时 PostgreSQL 容器执行完整迁移及单元/集成测试，不使用个人数据库。
- AiOrganizerTest：覆盖完整性、拒绝遗漏/重复/未知来源、单条保留、快照格式、输入限制、地址过滤。
- AiTransportTest：本地假服务验证三种协议的请求/响应、密钥头、不重试、不跳转、私网 opt-in。
- PostgresTest：加密与账号隔离、默认模型、后台任务、重复请求、编辑版本、失败保留旧稿、单向来源标记、不确定状态恢复。
- 浏览器：真实本地页面检查模型设置、未配置引导；使用仅在隔离测试页中拦截 API 的 fixture 验证生成、编辑、切换、勾选、发送后的两个状态列表。fixture 不是产品代码，测试结束关闭隔离页。
- 尚未使用用户付费模型进行实网生成，也没有向用户 flomo 发送测试笔记。具体供应商实网兼容性需配置后验证。
