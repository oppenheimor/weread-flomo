# 拾墨介绍页

- 生产路径：`/shimo/introduction`（构建时 `APP_BASE_PATH=/shimo/`）。根路径开发模式对应 `/introduction`。
- 页面：`web/Introduction.tsx`；样式：`web/introduction.css`。
- 页面在登录组件之外渲染，不请求账号或笔记 API。Java 仅为 `/introduction` 和 `/introduction/` 增加匿名访问与首页转发，保留其他路径的鉴权。
- 仅在登录后的应用顶部导航保留“关于拾墨”入口，在新窗口打开，不丢失当前笔记选择。登录、注册及登录加载页面不显示该入口。

## 内容依据

作者确认的动机：希望微信读书划线进入 flomo 后，书与书、书与生活能产生联系，让 flomo 成为更好的第二大脑。拾墨负责整理和发送，关联与思考由使用者完成。功能说明按当前代码核对，正文经过 humanizer-zh 润色；没有添加未经确认的个人经历。
