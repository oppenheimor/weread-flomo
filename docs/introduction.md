# 拾墨介绍页

- 生产路径：`/shimo/introduction`（构建时 `APP_BASE_PATH=/shimo/`）；开发路径：`/introduction`。
- 页面：`web/Introduction.tsx`；样式：`web/introduction.css`。
- 页面在登录组件之外渲染，不请求账号或笔记 API。Java 为 `/introduction` 和 `/introduction/` 增加匿名访问与首页转发，保留其他路径的鉴权。
- 登录后顶部导航提供“关于拾墨”，在新窗口打开，不丢失当前笔记选择。登录、注册及登录加载页面不显示该入口。

## 内容依据

作者确认的动机：希望微信读书划线进入 flomo 后，书与书、书与生活能产生联系，让 flomo 成为更好的第二大脑。拾墨负责整理和发送，关联与思考由使用者完成。正文保留原有作者声音，没有添加未经确认的个人经历。

在挑选笔记之后介绍 AI 整理、书架／单书分享、同步统计，再回到“有些事，还是留给自己”。

- AI 只整理同一本书、同一章节，保留来源供核对；先展示整理结果界面，再介绍自选模型。说明笔记会交给所选模型处理。
- 分享独立于 flomo，访客免登录，展示微信读书原始内容。说明全量分享、不可逐条隐藏、新内容随刷新更新，以及关闭后旧链接永久失效的边界。
- 统计按成功同步的原始笔记计数，而非 AI 卡片数或阅读时长。日期交互展示当天同步数量，不声称有尚未实现的书籍明细。
- 开始前的说明区分微信读书连接、可选的 flomo 配置和 AI 模型配置。

书架、笔记、AI 结果和统计以设备缩放 3 倍重新渲染截图；分享及模型弹窗为 4 倍，避免小弹窗在正文中被放大后发糊。不是对旧图片插值放大。弹窗仅在截图页临时去掉外沿圆角和阴影，裁掉边框，得到没有背景蒙层的矩形；正文用自己的圆角容器呈现。AI 图聚焦章节切换、观点卡片和来源区，省去大面积无关空白。

真实截图来自本地前端 5175／后端 18081。笔记仅临时勾选一条，拍摄后已取消。未发送、修改或删除笔记，未调用模型生成或测试，未公开私人想法。

演示数据通过本地 fixture 提供，完全不连接微信读书、flomo 或真实数据库：

```bash
APP_BASE_PATH=/ npm run build -- --outDir /tmp/shimo-intro-images
SHARE_UI_DIST=/tmp/shimo-intro-images SHARE_UI_INTRODUCTION=1 node scripts/share-ui-fixture.mjs
# http://127.0.0.1:4189/
```

所有截图固定为浅色，支持点击查看原尺寸；介绍页本身支持深浅主题。截图文件通过 `cwebp -lossless` 转换。
