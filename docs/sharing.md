# 书架与单书分享

## 使用

- 我的书架 → 分享书架；书内顶部 → 分享本书。
- 打开面板不会公开内容，点击“开启分享并复制链接”才创建链接。
- 开启后可复制、预览、关闭。关闭需确认，原链接永久失效，再开启得到新链接。
- 桌面使用紧凑对话框，手机为底部面板；复制失败时保留可手动选择的链接。
- 分享页面无需账号和凭证，独立于登录工作台。只读、无同步状态、无勾选/AI/编辑按钮。
- 书架内的书可返回该分享书架；独立单书链接不提供完整书架入口。

## 接口与存储

- `GET /api/shares[?bookId=...]`：当前账号的分享状态。
- `POST /api/shares`：`{bookId: null | string, enabled: boolean}`。登录、CSRF、同源校验均保留。
- `GET /api/public/shares/{token}[?bookId=...]`：匿名只读；单书 token 不允许读取其他书籍。
- `/share/{token}`：公开 HTML 入口；无效 token 返回 HTTP 404，并加载插画兜底页。
- 支持部署子路径，链接由前端 `BASE_URL` 生成。
- Flyway `V11__public_shares.sql`：每用户、每范围一条记录，书架使用空 book_id；关闭删除记录。
- 256 位随机 URL-safe token，不含用户 ID、账号名或 API key；并发开启同一范围返回同一链接。
- 返回 `Cache-Control: no-store`、`Referrer-Policy: no-referrer`、禁止索引响应头；浏览器从 bfcache 恢复时重新验证。
- 读取完成后再次检查 token，避免拉取期间关闭分享仍返回数据。
- 匿名上游任务最多并行 4 个，每分享人最多并行 2 个，每分钟最多 60 次。超限返回 429，不占私人同步锁。

## 数据边界

复用 RemoteApis 和 Normalizer，不调用 NotebookService 的预览/账本过滤，不返回同步状态、来源键数组、用户凭证或用户 ID。书架列表额外返回分享人的用户名，用于“用户名 的书架”标题；单书详情的用户名为空。内容包含书籍元数据、原始划线、原始想法、章节和创建时间。

书架范围与现有应用一致：`/user/notebooks` 返回的全部书目，并非新增了一个能枚举微信读书所有无笔记藏书的接口。对上游仍在返回的无笔记书籍，展示正常空状态。

每次刷新重新请求微信读书，不落库内容、不做快照。已同步、在工作台删除或改写过的笔记仍展示微信读书原文。单书访问时后端获取书目以验证存在并补齐元数据，但不会向访客返回其他书目。

微信读书凭证或上游错误统一返回 503 与通用提示，不泄漏原始错误，不误报 404。失效/不存在的分享或范围之外的书籍返回 404。

## 验证

- `npm run build`：通过。
- `npm run test:postgres`：90 项通过，含真实临时 PostgreSQL/Flyway、分享生命周期、账号隔离、匿名读取、CSRF/Origin、并发幂等、关闭期间读取、实时更新、原始内容隔离、限流与子路径路由。
- `node --test scripts/*.test.ts`：18 项通过。
- 浏览器验收：桌面、768px、390px、320px；明暗主题；章节切换、空笔记、错误重试、关闭→失效→重新开启、无勾选控件、单书无书架入口、无横向溢出。
- 浏览器使用 `scripts/share-ui-fixture.mjs` 的合成数据，不是用户的真实微信读书内容；后端集成测试 mock 上游，未对真实用户开启分享或调用 flomo。
- 截图见 `docs/research/share-ui/verification/`。仅作验收证据，非产品资源。

本地复验：先 `npm run build`，再 `node scripts/share-ui-fixture.mjs`，打开 `http://127.0.0.1:4189`。脚本仅监听回环地址，无外部服务请求。

## 上线说明

后端必须更新/重启，启动时 Flyway 自动创建 V11 表；同时更新同一次构建的前端。没有新增环境变量。不要只更新前端而继续运行旧后端。

已按用户要求重启本地 Java 后端（127.0.0.1:18081），V11 迁移成功，健康检查返回 200；未发布线上服务。前端开发服务保留在 5175。

分享状态读取失败时，面板显示独立的短标题和辅助说明，右下角提供“重新读取”，不再展示同步发送专用的报错文案。已用本地 fixture 验证错误→重试成功，检查桌面深色与手机浅色布局。可用 `SHARE_UI_FAIL_STATE=1 node scripts/share-ui-fixture.mjs` 复验一次失败。
